# Definition of Done
- [ ] Contesto e impatto verificati
- [ ] `npm run build` eseguito con successo; rendering controllato se cambia la UI
- [ ] Fonti impattate aggiornate o motivate come invariate (README, mappa, AGENTS)
- [ ] Madre aggiornata se cambia lo stato del sito (registro, handoff, changelog)
- [ ] Decisioni su brand rispettate: nessun colore, font o logo definitivo inventato
- [ ] Diff e collegamenti controllati
- [ ] HANDOFF aggiornato se sessione significativa
- [ ] Limiti e verifiche mancanti dichiarati; commit, push e deploy solo se autorizzati
